# Measured result: distilled vs scratch EdgeConv student (runs of 2026-08-04)

Companion to `prediction_20260804.md`, which was written **before** these runs finished
and is deliberately left unedited as a pre-registration record.

Runs: jobs 30335 (distilled) / 30337 (scratch), 30 epochs each,
`teacher_deepmet/trainL1_student_distill.py`, identical architecture, loss, schedule and
data split; the only difference is `--teacher_ckpt`.
Numbers below recomputed from the committed `.resolutions` files on 2026-09-18.

## Headline: distillation is a null result

Scaled resolutions (σ/R, GeV) in qT 50–150 / 150–300 GeV; plateau R averaged over 50–300 GeV.

| model | params | scaled σ(u⊥) | scaled σ(u∥) | plateau R |
|---|---|---|---|---|
| PUPPI baseline | — | 29.7 / 29.2 | 49.9 / 68.3 | 0.816 |
| v1 teacher | 6.4k | 25.5 / 27.5 | 43.5 / 62.5 | 0.782 |
| student, scratch | 6.4k | 25.2 / 25.6 | 43.1 / 57.8 | 0.855 |
| student, distilled | 6.4k | 25.1 / 25.6 | 42.8 / 57.9 | 0.846 |
| GraphNet teacher | 129k | 24.3 / 24.5 | 39.5 / 54.6 | 0.866 |
| ParT teacher (ideal) | 138k | 24.9 / 24.2 | 31.8 / 53.8 | 0.874 |

Every scratch-vs-distilled delta is ≤ 0.3 GeV (≤ 0.6 %), within run-to-run noise, and
the distilled student is slightly worse on plateau response.

## Diagnostic: mimicry succeeded, transfer failed

Per-particle weight MSE against the teacher target `s·w`, over 3,072 validation events:

| | weight MSE vs teacher | mean weight |
|---|---|---|
| PUPPI | 0.470 | 0.916 |
| student, scratch | 0.350 | 1.027 |
| student, distilled | 0.230 | 0.908 |
| teacher (target) | — | 0.906 |

The distilled student matches the teacher's weights 34 % better and its mean weight to
0.2 %, and no physics metric moves. The teacher's per-particle weight pattern is not the
carrier of its advantage; the residual ParT edge lives in global-event-context structure
two local EdgeConv hops cannot represent at any weight target.

## Scoring the pre-registration

All five pre-registered metric bands contained the measured value. Of the three headline
bets:

1. "Distilled student ≈ v1 teacher despite far fewer params" — **correct** (it beats v1
   on every metric), though for the wrong reason: the gain came from the loss/head/seam
   work, not from the teacher.
2. "Distillation net gain is real but modest, ~2–3 GeV on scaled u∥" — **wrong**. Actual
   ~0.2 GeV, i.e. zero.
3. "Gap to ParT on u∥ 50–150 stays large (student ~44 vs 31.8)" — **correct** (43.1).
   As pre-committed, this makes a cheap global feature for the student the next move
   rather than more distillation.

## Erratum

`prediction_20260804.md` and the original `compare_students.py` legend label the v1
teacher "173k". That is wrong: the v1 teacher checkpoint
(`teacher_ckpts_L1_fixed/best.pth.tar`) has **6,417 trainable parameters** — the same
size as the student, because the PV-association embedding that would distinguish them
does not exist in L1 data. The legend has been corrected; the pre-registration file is
left as written. No conclusion depends on this: the distillation teacher is ParT
(137,926 params), and the student is 4.7 % of it.
